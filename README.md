# Likes FF - Platform Beli Likes

🔥 **Website resmi untuk membeli likes Free Fire, TikTok, Instagram dan services lainnya**

## Fitur

✅ **Likes Free Fire** - Dapatkan likes suntik untuk profil Free Fire Anda  
✅ **TikTok Likes & Followers** - Boost engagement video TikTok  
✅ **Instagram Followers** - Tambah followers Instagram real  
✅ **Views TikTok** - Tingkatkan jumlah views video  
✅ **Reaksi Channel** - Tambah reaksi untuk channel Anda  
✅ **Harga Terjangkau** - Paket lengkap dengan harga bersaing  

## Teknologi

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **UI Colors**: Merah (#DC143C) • Biru (#1E40AF) • Kuning (#FCD34D)
- **Hosting**: Vercel

## Mulai Development

```bash
# Install dependencies
npm install

# Jalankan development server
npm run dev

# Buka browser
# http://localhost:3000
```

## Deploy ke Vercel

1. Push ke GitHub
2. Buka [Vercel](https://vercel.com)
3. Import repository ini
4. Deploy dengan 1 klik!
